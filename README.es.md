# Purgeatory Enhanced

Avisa cuando vos o tu mascota cortan, disipan, purgan, roban, reflejan o absorben con un tótem un hechizo enemigo, en World of Warcraft 3.3.5a (WotLK).

Basado en **Purgeatory** de **Mayen** (modificado por **Sithis**). Todo el crédito del addon original es de sus autores.

## Qué cambia en esta versión

- Un menú de opciones compacto (`/purg`): tamaño, posición, **Mover** y **Reset**.
- Menos uso de memoria y CPU, y varios bugs arreglados.

## Instalación

1. Descargá este repositorio (**Code → Download ZIP**).
2. Copiá la carpeta `Purgeatory` en `World of Warcraft/Interface/AddOns/`.
