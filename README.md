# Purgeatory Enhanced

Announces when you or your pet interrupt, dispel, purge, steal, reflect or ground an enemy spell, for World of Warcraft 3.3.5a (WotLK).

Based on **Purgeatory** by **Mayen** (modified by **Sithis**). All credit for the original addon goes to its authors.

## What this version does differently

- A compact options menu (`/purg`): size, position, **Move** and **Reset**.
- Lower memory and CPU use, and several bug fixes.

## Installation

1. Download this repository (**Code → Download ZIP**).
2. Copy the `Purgeatory` folder into `World of Warcraft/Interface/AddOns/`.
